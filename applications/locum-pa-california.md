## Before you apply

- Agencies will ask for a **California license** (or proof it is pending) before submitting you to a facility. Pending is
  common, but many assignments start only after issue, so lead with the expected date.
- Ask each agency: W-2 or 1099, malpractice coverage and tail, travel/housing, shift length, and
  whether supervision is by delegation to a named physician. The Barton listing mentions practising
  independent of physician supervision; confirm how that works under California PA rules before
  accepting.
- Credentialing paperwork takes weeks. Start NCCPA verification, ACLS/BLS copies, and references now.
